# Cable Creative Roleplay | Bypasses Guide

*If you have any suggestions for this document, please let us know on Discord!*

Bypasses have changed yet again. Now **you** control everything in-game with commands.

## Initial Setup

- /bypassgroup or /bg  
- /bg create {name} {Hex color code} - **Used to create a group for the first time**.

## Usage

Use these to edit the group you just made.

- /bg name {name} - **Used to edit the name**  
- /bg color {color} - **Used to edit the color**

This is how you now add bypasses to yourself.

- /bypassitem {id} or /bi {id}  
- /bypassvehicle {id} or /bv {id}

In order to remove an item or vehicle from your bypasses simply enter the command and id again then follow the prompt to confirm or cancel (expires after 30 seconds)

- /bi confirm  
- /bv confirm

To check your current bypasses.

- /bypasses
